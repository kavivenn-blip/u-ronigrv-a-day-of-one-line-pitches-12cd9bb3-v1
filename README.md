## Run it

```sh
python3 main.py
```

The program writes one sentence to `/output/entry.txt` (129 characters, UTF-8, no trailing newline). Deterministic: two runs from a clean copy produce byte-identical output. No network, no dependencies, no files outside this repository.

## The sentence

> Forget the rule that you must learn to code: hand your gift-list idea to an AI agent on make.fun and let it build your first app.
